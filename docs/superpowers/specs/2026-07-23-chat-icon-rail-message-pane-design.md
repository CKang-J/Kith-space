# Kith-space 图标导航栏与消息中栏设计

- 日期：2026-07-23（2026-07-24 消息视觉细化）
- 状态：已实现并完成自动化与浏览器视觉验收，待用户最终确认
- 范围：工作区图标导航、消息中栏、主消息气泡与话题分栏
- 非目标：Composer、消息搜索、数据模型、URL 与业务模块内部布局
- 覆盖：取代 `2026-07-15-chat-shell-sidebar-module-navigation-design.md` 中“图标 + 文字的单一左侧栏”视觉结构；其单窗口、URL、模块同槽位切换与 Settings 模态层契约继续有效

## 1. 目标

工作区采用参考图的三段式架构：

```text
窄图标导航栏 | 消息中栏（频道 / 私信） | 当前聊天
```

左侧第一层只承担全局工作区导航，第二层只承担消息会话导航，主区只承担当前会话。模块打开后窄图标导航栏继续常驻，业务模块仍在右侧唯一主工作区原位替换 Chat。

## 2. 窄图标导航栏

- 固定宽度 `68px`，背景使用 `#f5f5f5`，不绘制右侧边线；消息中栏与主区的必要分隔线统一收浅至约 `#f0f0f0`。
- 顶部保留 Space 图标和 Space 切换能力。
- 导航顺序为 `Messages | Search | Spaces(Home only) | Inbox | Tasks | Agents | Settings`。
- 所有入口只显示图标；每个按钮必须有 `aria-label`，鼠标 hover 或键盘 focus 时在右侧显示功能名 tooltip。
- Messages 是正式导航入口。Chat 激活时它显示选中态；从业务模块点击 Messages 会移除模块 query 并返回当前 Chat。
- Search 继续打开既有全局命令面板，不在消息中栏增加第二个搜索框。

## 3. 消息中栏

- 仅在 Messages/Chat 激活时显示，桌面宽度使用 `clamp(228px, 22vw, 282px)`。
- 顶部显示“消息”标题；不显示搜索框。
- 已保存、频道、私信与底部 Agent 运行状态继续复用既有数据和交互。
- 频道和私信必须有明确分组标题及各自的新建入口。
- 频道行使用图标方块，私信行使用 Agent 头像；选中行使用浅蓝表面，hover 使用浅中性色。
- 切换 Spaces、Inbox、Tasks 或 Agents 后，消息中栏随 Chat 一起退出，避免把会话导航误当成所有模块的共同对象侧栏。

## 4. 消息表现

- Human 消息右对齐，头像位于气泡右侧，不重复显示自己的昵称和时间标题。
- Human 气泡使用浅蓝 `#e7f0fe`；Agent 气泡左对齐并使用更轻的中性浅灰 `#f7f8fa`，两者统一使用 `16px` 圆角与 `16px 18px` 内距。
- 消息头像统一为 `36px`。频道中的 Agent 保留紧凑昵称行，气泡顶部落在头像圆心高度；私聊不重复显示 Agent 昵称，气泡顶部与头像顶部平齐。
- Agent 消息时间只显示 `HH:mm`，位于气泡下方；默认隐藏，仅在当前消息 hover 或 focus-within 时显示，触屏设备保持可见以免丢失信息。
- hover 工具栏与“更多”菜单共用白色表面、`#f0f0f0` 边线、`12px` 圆角和轻量投影；Agent 工具栏优先出现在气泡右侧，Human 工具栏优先出现在气泡左侧，各自侧边空间不足时移到气泡上方。
- Agent 昵称使用常规字重。话题回复预览从消息气泡中分离为独立白色描边卡片，保留最近回复内容、回复数和“最新 N 分钟前”，hover 时表面加深。
- 展开话题时，当前会话标题栏仍横跨完整 Chat 宽度，右侧操作按钮不因话题分栏而移位；话题分栏从该标题栏及其连续浅色分割线下方开始，不遮盖或复制主标题栏。话题工具栏使用 `16px` 标题和 `44px` 高度，操作按钮为 `28px`。父消息外层不增加第二层背景；话题内 Agent 头像左边距、Human 头像右边距以及 Agent 气泡右边距使用同一安全边距。
- 聚合面板顶部新增与 Chat 标题栏同高的 `52px` 标题栏，显示“聚合面板”和圆形 hover 关闭按钮，底部分割线与 Chat 标题栏对齐；“轨迹 / 话题 / 文件”分段控制器移到标题栏下方，控制器自身不再绘制下边线。聚合面板、频道响应方式和 Agent 默认响应方式统一复用公共分段控件的 `#f5f5f5` 轨道、40px常规高度、2px内缩、12px轨道圆角、10px选中圆角、常规500字重、白色选中底板和轻量多层投影，紧凑卡片只保留必要的高度差。
- 消息外层不绘制整行卡片。
- 日期分隔改为居中灰色胶囊，不再使用贯穿消息区的水平线。
- 既有 reaction、话题、复制、更多、附件、任务、提及与身份卡片行为不变。

## 5. 明确不变

- 本轮不修改 Composer 的尺寸、布局、文案、附件区、任务胶囊或发送行为。
- 消息中栏不新增搜索框；全局搜索继续由图标栏 Search 和 `Cmd/Ctrl + K` 唤出。
- 不修改会话、消息、任务、Agent 或 Space 的服务端协议和数据库结构。
- Settings 继续使用模态层；业务模块继续复用唯一主工作区槽位。

## 6. 组件边界

- `WorkspaceNavigationRail.tsx`：组合 SpaceSwitcher 与全局图标导航，并负责 Messages 返回 Chat。
- `SidebarModuleNavigation.tsx`：只负责图标、激活态、tooltip 与模块选择回调。
- `ChatSidebar.tsx`：只负责消息中栏标题、会话分组和运行状态。
- `ConversationListContent.tsx`：继续复用已保存、频道、归档频道与私信的数据/交互。
- `ChatMessageItem.tsx` 与 `chatMessage.css`：继续作为统一消息骨架，只调整 Human/Agent 的方向与语义表面。
- `WorkspaceFrame.tsx`：组合图标导航、ChatWorkspace、业务模块与 Settings，不新增第二状态源。
